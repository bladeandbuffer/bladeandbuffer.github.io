2D Animations

Animations for mobile games (1M+ installs)

I've worked on a range of 2D animations: directly inside the Unity engine system, in Spine, and even via code using DoTween and other tweening tools. For UI, I prefer tween-based animation.

I can also animate simple characters, since I know the core techniques needed to create solid animations.

Of course, asset preparation plays an important role: slicing them or exporting them from Photoshop, and then packing them into atlases. For example, the images you see above used only a single draw call.
